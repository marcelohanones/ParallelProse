This project is about comparing two corpuses over an issue. It uses RAG as the core engine. The project started as a single RAG system to answer queries about a corpus and than evolved to a comparison tool. As it turned to a more compreheensive system many features were added along the way. There are notebooks experessing the architecture in effect for each version.
